# AE-variants

Code for the simulations using:

* Variational autoencoders (https://github.com/Junjie-Zhu/VAE): packed_vae.py
* Wasserstein autoencoders: packed_wae.py 
* Denoising autoencoders: packed_dae.py 

The Python version used was 3.7.4 and the modules in the environment are listed
in the *requirements.txt* file. Installation steps are similar to those provided 
in Junjie-Zhu's repository.
